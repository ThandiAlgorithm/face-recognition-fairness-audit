# AMEND-20260918-01

## Type

method_change_before_results

No confirmatory fairness analysis has run at any point in this project — Phase 0 explicitly stops before confirmatory comparisons (see PR description). There is no result to have been influenced by this change.

## Change

Change the canonical UTKFace source from the aligned and cropped release to the official In the wild Faces release.

## Reason

The Phase 0 design requires RetinaFace detection and project alignment to be auditable on raw eligible images. The aligned and cropped UTKFace variant bypasses those pipeline stages and does not match the intended canonical source decision.

## Confirmatory result viewed before this change

no

## Effect

The canonical UTKFace source paths, file manifest, stable image IDs, duplicate checks, splits, detection outputs, alignment outputs, visual measures, skin measures, dataset counts, and downstream tables must be regenerated.
