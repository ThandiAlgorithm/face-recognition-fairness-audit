# AMEND-20260922-01
## Stratified human review of perceptual duplicate candidates

### Classification
result_informed_method_change

### Background

The Phase 0 duplicate-screening pipeline generated 61,553
perceptual candidate image pairs.

Exhaustive cross-dataset review showed that the candidate
generator had a high false-positive rate:

- 23,865 cross-dataset pairs classified as false alarms
- 0 confirmed cross-dataset duplicates
- 1 uncertain cross-dataset pair

Within-dataset candidate inspection showed that the majority
of unresolved candidates belonged to a single weak-evidence
stratum:

- candidate_method = crop
- crop_matching_regions = 2

This produced an impractically large manual-review burden.

### Amendment

Within-dataset perceptual candidates are divided into two
review strata.

#### Stronger-evidence stratum

The following candidates are reviewed exhaustively:

- candidate_method = phash
- candidate_method = phash+crop
- crop-only candidates with crop_matching_regions >= 3

At stratification, 4,513 unresolved pairs were assigned to
this stratum.

Human review result:

- confirmed: 1,210
- false_alarm: 3,298
- uncertain: 5
- unresolved candidate: 0

#### Weak-evidence stratum

The weak stratum is defined as:

- candidate_method = crop
- crop_matching_regions = 2

At stratification, 30,328 unresolved pairs belonged to this
population.

A deterministic simple random sample was drawn:

- sample size: 1,000
- random seed: 26041
- sampling without replacement

Human review result:

- confirmed: 0
- false_alarm: 1,000
- uncertain: 0

The remaining 29,328 weak-stratum pairs were not individually
human-reviewed.

### Addendum: pre-stratification bulk decisions (discovered 2026-09-23)

During Phase 0 closure validation, the live weak-evidence stratum
was found to contain 33,083 pairs, not the 30,328 recorded above.

This does not change the 30,328 figure, the 1,000-pair sample, or
the 29,328 retained-candidate figure. Those numbers are correct as
a description of the population that was still unresolved at the
moment stratification ran.

The difference is 2,755 additional weak-stratum pairs
(candidate_method = crop, crop_matching_regions = 2,
within-dataset) that were already `false_alarm` before
stratification ran. They were resolved earlier, via the grid
reviewer's bulk "mark all visible false" action, during the
manual review attempt described in the Background section above
-- the one that was found to be impractically large and prompted
this amendment. Because they were no longer `candidate` at
stratification time, `prepare_duplicate_review_strata.py`
correctly excluded them from the 30,328-pair population.

Audit trail:

- Source: `metadata/near_duplicate_review.csv.journal.csv`
- All 2,755 pairs have matching journal entries, timestamped
  2026-09-20T21:39 through 2026-09-22T06:59:41, entirely before
  the strong-evidence stratum journal begins
  (2026-09-22T07:14:16).
- Many entries share identical (second-resolution) timestamps in
  bursts of up to 715, consistent with the grid reviewer's bulk
  action rather than pair-by-pair review: a person visually
  reviewed an anchor image's full candidate grid, then resolved
  the visible batch at once.
- Every affected pair is recorded as `false_alarm` in both the
  journal and the live review file.

Current full weak-stratum accounting:

- Seed-26041 sample, reviewed: 1,000
- Pre-stratification bulk decisions (false_alarm): 2,755
- Retained, unreviewed candidates: 29,328
- Total: 33,083

This is a factual reconciliation, not a protocol decision. The
bulk-review method (grid-level visual inspection, not per-pair
individual review) has not been evaluated against whatever review
standard the approved protocol requires. Whether these 2,755
decisions satisfy formal acceptance remains open and is not
resolved by this addendum -- it is subject to the same pending
approval as the rest of this amendment.

### Treatment of unsampled weak candidates

Unsampled weak-stratum pairs MUST NOT be represented as
individually reviewed false alarms.

They remain explicitly identifiable as unreviewed weak
screening candidates.

Only human-confirmed perceptual pairs may create
near-duplicate groups.

Candidate or uncertain status alone does not create a
near-duplicate group.

### Cross-dataset treatment

Cross-dataset perceptual candidates were reviewed exhaustively.

Result:

- confirmed: 0
- false_alarm: 23,865
- uncertain: 1
- unresolved candidate: 0

No cross-dataset duplicate is therefore marked confirmed from
the perceptual-review stage.

### Scientific rationale

The amendment changes the human-review workload, not the
underlying perceptual candidate-generation thresholds.

The following remain unchanged:

- perceptual hash algorithms
- crop-resistant hash construction
- Hamming thresholds
- candidate-generation results
- original candidate records

The full candidate set is retained for auditability.
