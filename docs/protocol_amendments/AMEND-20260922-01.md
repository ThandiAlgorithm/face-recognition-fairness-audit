# AMEND-20260922-01
## Stratified human review of perceptual duplicate candidates

### Classification
result_informed_method_change

### Background

The Phase 0 duplicate-screening pipeline generated 61,553
perceptual candidate image pairs.

Exhaustive cross-dataset review showed that the candidate
generator had a high false-positive rate:

- 23,865 cross-dataset pairs classified as false alarms
- 0 confirmed cross-dataset duplicates
- 1 uncertain cross-dataset pair

Within-dataset candidate inspection showed that the majority
of unresolved candidates belonged to a single weak-evidence
stratum:

- candidate_method = crop
- crop_matching_regions = 2

This produced an impractically large manual-review burden.

### Amendment

Within-dataset perceptual candidates are divided into two
review strata.

#### Stronger-evidence stratum

The following candidates are reviewed exhaustively:

- candidate_method = phash
- candidate_method = phash+crop
- crop-only candidates with crop_matching_regions >= 3

At stratification, 4,513 unresolved pairs were assigned to
this stratum.

Human review result:

- confirmed: 1,210
- false_alarm: 3,298
- uncertain: 5
- unresolved candidate: 0

#### Weak-evidence stratum

The weak stratum is defined as:

- candidate_method = crop
- crop_matching_regions = 2

At stratification, 30,328 unresolved pairs belonged to this
population.

A deterministic simple random sample was drawn:

- sample size: 1,000
- random seed: 26041
- sampling without replacement

Human review result:

- confirmed: 0
- false_alarm: 1,000
- uncertain: 0

The remaining 29,328 weak-stratum pairs were not individually
human-reviewed.

### Treatment of unsampled weak candidates

Unsampled weak-stratum pairs MUST NOT be represented as
individually reviewed false alarms.

They remain explicitly identifiable as unreviewed weak
screening candidates.

Only human-confirmed perceptual pairs may create
near-duplicate groups.

Candidate or uncertain status alone does not create a
near-duplicate group.

### Cross-dataset treatment

Cross-dataset perceptual candidates were reviewed exhaustively.

Result:

- confirmed: 0
- false_alarm: 23,865
- uncertain: 1
- unresolved candidate: 0

No cross-dataset duplicate is therefore marked confirmed from
the perceptual-review stage.

### Scientific rationale

The amendment changes the human-review workload, not the
underlying perceptual candidate-generation thresholds.

The following remain unchanged:

- perceptual hash algorithms
- crop-resistant hash construction
- Hamming thresholds
- candidate-generation results
- original candidate records

The full candidate set is retained for auditability.
