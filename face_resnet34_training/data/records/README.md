# records.csv schema

Generated by `src/datasets/records.py`. One row per image, built from
`metadata/master_annotations.parquet` (+ `metadata/master_annotations_lfw_demographics_derived.parquet`
for LFW's race/gender). Not committed to git -- see `records_summary.json`
for row counts and file hashes; rerun `records.py` to regenerate exactly.

| column | meaning |
|---|---|
| `image_id` | joins back to `master_annotations.parquet` |
| `image_path` | repo-root-relative path to the Phase 0 aligned/cropped image actually used for training; null if unresolvable |
| `dataset` | `lfw` / `fairface` / `utkface` |
| `identity_id` | LFW `subject_id`; null for FairFace/UTKFace (no reliable identity IDs) |
| `race_label`, `race_source` | race + provenance (`native` or `derived_kumar2009_attribute_classifier` for LFW) |
| `gender_label`, `gender_source` | gender + provenance (`native` or `derived_lfw_name_lists` for LFW) |
| `age_value`, `age_source` | continuous age where available (UTKFace only) |
| `age_group` | native age band (FairFace/UTKFace); null for LFW |
| `ita_value` | Phase 0's continuous ITA measurement, reused as-is, never recomputed |
| `ita_group` | Phase 0's frozen GOV-002 binary ITA split (`skin_group_ita`, threshold `ITA > 28`), carried through unchanged |
| `alignment_valid`, `exclusion_reason` | native Phase 0 flags (see note below for LFW) |
| `eligible_demographic_audit` | native, except LFW rows where the lfw-rep PR's approved override applies |
| `eligible_demographic_audit_overridden` | True only for the LFW rows where the override above applies |
| `exact_dup_group`, `near_dup_group`, `cross_dataset_dup` | Phase 0's own duplicate-detection results, reused for split-leakage prevention |
| `image_sha256` | SHA256 of the aligned image file actually read for training |
| `phash` | perceptual hash (requires `imagehash`; null until installed) |
| `attr_*` (LFW only, 40 columns) | LFWA+ binary attributes from `lfw_att_40.mat` -- the LFW model's actual multi-label training target. Note LFWA+ has no race attributes; race_label/gender_label above come from a different source and are for subgroup/fairness analysis, not part of this head. |

**LFW `exclusion_reason` note**: every LFW row shows `missing_required_label`
-- that's the native, pre-derivation value and is intentionally left as
historical provenance. The field that actually governs eligibility post
LFW-demographics-derivation is `eligible_demographic_audit` (+ the
`_overridden` flag), not `exclusion_reason`.
